# PKI Next Generation (pkiNG)

## Overview

**pkiNG is a collection of resources**, references and labs that create an environment for designing, building, testing and scale cryptographic algorithms, protocols and architectures.  

**pkiNG is based on a blog post**, "[Build a Tiny Certificate Authority For Your Homelab](https://smallstep.com/blog/build-a-tiny-ca-with-raspberry-pi-yubikey/) ", which creates a light weight PKI for a home network using a Raspberry PI and Smallstep's `step-ca`.

**pkiNG attempts to create clear "speration of concerns"** by adopting  [OmniTech's ILM]([dd](https://www.omnitrust.com/ilm/)) architecture.
